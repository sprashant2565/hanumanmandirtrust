# Hanuman Mandir Trust - Frontend

A responsive, static frontend website for Hanuman Mandir Trust / Saravatkhani Hanuman Mandir.

## Included
- `index.html` - page structure and trust information
- `style.css` - responsive devotional theme
- `assets/hanuman-ji.jpeg` - supplied Hanuman Ji photograph used as the main visual/logo
- No backend, database, login, or API is required.

## Run locally
Open `index.html` directly in a browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Updating later
- Replace/add member photos in `assets/`.
- Update the members section in `index.html`.
- Update the announcement text in the `#updates` section.
- Add an Events/Gallery section when required.
